# "Mine" Tab (Tasks Assigned to Me)

- Date: 2026-10-18
- Status: approved (user requested the tab and approved the proposal on 2026-10-18)
- Context: tasks can be assigned to a person, but there was no personal view; people had to scan the whole project list to find their own work.
- Decision: owners and users get a third tab, **Mine** (AppBar title "Assigned to me"), after Tasks. It shows only tasks with `assignee_id` equal to the logged-in person, enforced in the application layer by the new `TaskService.watchTasksAssignedTo` method — not just by hiding rows. Admins do not get the tab: they have no project and can never be an assignee, so it would always be empty (capability matrix unchanged).
- Implementation: `visibleTabs` now returns `['members', 'tasks', 'mine']` for owner/user; the shared `TaskListView` (extracted from the Tasks tab) renders search, stats cards, filter chips, grouped sections, swipe + undo, and pull-to-refresh for both scopes; `MyTasksTab` wires it to `myTasksProvider`.
- Verification: `flutter analyze` clean; `flutter test` 34/34 passed (updated rules and shell tests plus new service and Mine-tab widget tests).
- Reverses: the tab lists in the access-control and flutter-ui skills (updated in this change).
- Still open: whether Mine should eventually span projects for admins (requires allowing admin assignees, which contradicts global admins having no project).
