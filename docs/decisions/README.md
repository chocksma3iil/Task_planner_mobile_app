# Decision Records

One file per material decision, named `YYYY-MM-DD-short-topic.md`, containing:

- Context — what made the decision necessary.
- Options considered — with trade-offs.
- Decision — what was chosen.
- Status — proposed or approved (with approver and date).
- Reverses — earlier decision this overturns, if any.
- Still open — follow-up questions left undecided, if any.
